# .github

> GitHub Actions workflows for CI/CD and publishing

Contains GitHub Actions workflows for continuous integration (linting, testing), frontend building, and PyPI package publishing. Ensures code quality and automates deployment.

## Files

### `.github/workflows/ci.yml`

Runs linting, testing, and frontend builds on push/pull requests

- `lint-and-test` (job) - Runs Ruff linter and pytest across multiple Python/OS versions
- `frontend` (job) - Builds the frontend using Node.js
- `wheel` (job) - Verifies the built wheel includes frontend assets

### `.github/workflows/publish.yml`

Publishes package to PyPI on release

- `publish` (job) - Builds frontend, creates Python package, verifies assets, and publishes to PyPI

## Key Concepts

- **Matrix testing**: Tests across multiple Python versions and operating systems
- **Frontend integration**: Ensures frontend assets are included in Python wheel

## Internal Relationships

- `ci.yml` → `publish.yml`: Both share frontend build and wheel verification steps
